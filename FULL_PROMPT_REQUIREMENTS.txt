# PART 3 — INSTAGRAM STORIES-STYLE CAROUSEL PROGRESS

The current carousel displays:

- Thin progress bars at the top.
- Previous button.
- Pause/play button.
- Next button.
- A numerical counter showing `1 / 4`.

The numerical counter is unnecessary.

**Remove the `1 / 4` counter completely.**

## 3.1. Required progress design

At the top of the carousel image, display thin horizontal segments.

If there are four active slides, display four segments.

Each segment represents one slide.

For example:

Slide 1:

- First segment gradually fills from left to right.
- Other segments remain unfilled.

Slide 2:

- First segment remains fully filled.
- Second segment starts filling.
- Third and fourth remain unfilled.

Slide 3:

- First and second segments remain filled.
- Third segment gradually fills.
- Fourth remains unfilled.

Slide 4:

- First three segments remain filled.
- Fourth segment gradually fills.

After the last slide finishes, return to the first slide and reset the progress sequence.

Use the brand's bright orange as the active progress color.

Use subtle translucent white/gray for the inactive tracks.

The result should feel refined and modern.

## 3.2. Timing

Default slide duration:

**5.5 seconds**

Progress duration must match slide duration exactly.

The progress bar must advance smoothly, not in obvious jumps.

The slide must transition only when the current progress reaches completion.

Use one coordinated timing mechanism for slide progression and visual progress.

Avoid multiple competing timers that cause desynchronization.

## 3.3. Manual navigation

When a visitor clicks Next:

- Move to the next slide immediately.
- Reset the current slide's progress to zero.
- Mark earlier segments appropriately.
- Begin progression from the newly selected slide when rotation is active.

When clicking Previous:

- Move to the previous slide.
- Update completed segments appropriately.
- Reset active progress.

When selecting a specific progress segment:

- Navigate to that slide.
- Update its active state.
- Reset timing appropriately.

Avoid delayed transitions after manual navigation.

Rapid clicking must not cause multiple overlapping animations.

## 3.4. Pause behavior

When the user pauses:

- Freeze the current progress at its exact position.
- Keep the current slide visible.
- Do not reset its progress.
- Resume from the same position when explicitly restarted.

Also handle:

- Mouse hover.
- Keyboard focus.
- Browser tab visibility.
- Reduced-motion preferences.

Follow the accessible carousel behavior specified by the W3C.

When focus enters an automatically rotating carousel, stop automatic rotation and do not restart it without an explicit user action.

Provide a clearly labeled rotation control for accessibility.

Keep the visual controls minimal.

## 3.5. Carousel presentation

Maintain the premium 4:5 photographic card.

Improve:

- Crossfade quality.
- Image loading.
- Text transition.
- Progress animation.
- Responsive cropping.
- Contrast.
- Control placement.

Avoid:

- Screen flashes.
- Excessive image zooming.
- Layout shifts.
- Unnecessary animation.
- Incorrect progress timing.
- Stale slide content.
- Hardcoded slide counts.
- Multiple animation intervals.

Keep the left-side hero content stable while the right-side carousel rotates.

## 3.6. Dynamic slide count
